# Project_Ruby

A lightweight browser-based 3D game engine prototype with:

- large-scale looping procedural terrain rendered as a wire mesh
- simulated rigid-body physics on spawned scene items
- lit 3D rendering with mouse-look and WASD camera controls
- procedurally sampled cave field visualization
- an in-app editor panel to spawn primitives, change terrain style, and adjust terrain generation

## Run

```bash
npm install
npm run dev
```

## Validate

```bash
npm test
npm run build
```
